# Project boundaries

- `tools/crop/` is the browser-only crop tool. `runtime/` contains offline and serial 60-second live single-image inference runners with a shared causal three-sample majority filter. Live ROI supports static transforms or optional CPU YOLO top1 detection/crop; do not claim reliable tracking, occlusion detection or safety guarantees. Ultralytics/derived weights retain their separate AGPL licensing.
- Keep this repository suitable for future publication. Never add real camera images, recordings, base64 camera footage, real calibration parameters, model outputs, credentials, local addresses or machine-specific deployment scripts, even while the repository is private.
- Keep all real data, images, labels, weights, runtime configuration and outputs outside the repository. `.local/` is only for non-sensitive scratch development; do not force-add ignored files.
- Use synthetic fixtures for tests. Run `npm ci --include=dev` and `npm test`; browser tests keep Chromium sandbox enabled. Runtime tests: `python -m unittest discover -s runtime -p 'test_*.py'` after installing `runtime/requirements.txt`.
- `training/` is optional original glue, not vendored Ultralytics. Pin and verify the isolated training environment; preserve AGPL/Enterprise boundaries for dependencies and pretrained/derived weights. Run `python -m unittest discover -s training/tests -p 'test_*.py' -v` on the designated target machine; never download models or real images in CI. Real smoke runs use train/val only, CPU by default, a separate private output directory, and must not alter production dependencies or prior experiments.
- Do not introduce an upload API or server-side persistence for the crop tool. It processes images locally and exports PNG/JSON for the user.
- JSON operations are ordered; crop coordinates refer to the immediately preceding output. Preserve clockwise rotation, expanded canvas and fill-color semantics.
- Check staged content and Git history before publishing; deleting a private asset from the current tree does not remove it from history.
